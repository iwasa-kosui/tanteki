# 本番キャッシュ再起動手順（ドラフト）

## 1. 実施条件
監視でエラーを検知した場合に、キャッシュ再起動を検討する。

ただし、以下は未確定のため、実施前に運用責任者の判断を仰ぐ。
- 再起動してよい条件
- 再起動を避ける条件
- 影響範囲・停止許容時間
- 実施者の承認要否

## 2. 実施手順
1. 監視で発生しているエラー、発生時刻、対象サービスを記録する。
2. 運用責任者へ連絡し、再起動の可否を確認する。
3. 承認後、対象キャッシュを停止・再起動する。
4. 再起動コマンドを実行する。

※対象ホスト、サービス名、停止コマンド、再起動コマンド、実行ユーザーおよび権限は未確定。確定後に記載する。

## 3. 復旧確認
再起動後、以下を確認する。
- 監視エラーが解消したこと
- キャッシュが正常に稼働していること
- アプリケーションからのアクセスが正常であること
- エラーや性能劣化が再発していないこと

※確認コマンド、確認画面、判定基準および確認時間は未確定。確定後に記載する。

## 4. 復旧しない場合
再起動後もエラーが継続する場合は、追加の再起動を繰り返さず、運用責任者へ状況を連絡して指示を受ける。

## 5. 連絡先・記録
実施前後に、以下を記録・連絡する。
- 発生したエラー
- 対象環境・対象キャッシュ
- 実施日時と実施者
- 実行した操作
- 復旧確認結果

※連絡先、連絡手段、エスカレーション先および記録場所は未確定。確定後に追記する。
